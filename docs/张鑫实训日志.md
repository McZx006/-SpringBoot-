# 张鑫实训日志

## 第一天

今天是实训的第一天，上午参加了项目启动会议，了解到本次实训项目是在线教学平台，采用前后端分离架构。我负责管理员端的前端开发，使用 Vue 2 + Element UI 技术栈。下午我克隆了项目代码，配置了 Vue CLI 开发环境，搭建了本地开发服务器。遇到了一些依赖安装问题，通过查阅文档和请教同事得以解决。晚上我阅读了项目的 README 文档和开发指南，初步熟悉了项目结构和代码规范。

通过第一天的学习和探索，我对项目整体有了初步认识，为后续的开发工作打下了基础。

---

## 第二天

今天我主要任务是学习 Vue 2 框架核心知识和项目架构设计。上午学习了 Vue 2 的响应式原理、组件化开发思想和生命周期钩子函数。下午阅读了管理员端现有代码，理解了项目的目录结构、路由配置、API 请求封装等内容。晚上尝试运行项目，熟悉了开发服务器的启动方式和项目的基本运行流程。

通过今天的学习，我掌握了 Vue 2 的核心概念，为后续页面开发提供了技术储备。

---

## 第三天

今天开始开发登录认证模块。上午设计了登录页面的 UI 布局，使用 Element UI 的表单组件构建了用户名、密码输入框和登录按钮。下午对接后端登录接口，调试了登录请求和响应处理。实现了登录表单验证功能，添加了必填校验和格式校验。晚上实现了 Token 存储和路由守卫机制，防止未登录用户访问管理页面。

登录模块的开发让我理解了前后端认证的完整流程，为后续功能开发奠定了基础。

---

## 第四天

今天继续完善登录模块并开始开发学员管理模块。上午处理了登录失败的错误提示，优化了登录页面的用户体验。下午开始学员管理模块开发，使用 Element UI 表格组件实现了学员列表展示，添加了分页功能。实现了新增学员弹窗，使用表单组件构建了学员信息录入界面。晚上对接了学员管理的增删改查接口，完成了学员管理的基础功能。

今天的工作让我熟悉了管理后台的标准开发模式，提高了 CRUD 功能的开发效率。

---

## 第五天

今天是实训第五天，主要完善学员管理模块并开发资料类型管理模块。上午为学员列表添加了关键词搜索功能，优化了查询参数的传递方式。实现了学员信息的编辑功能，使用弹窗表单加载现有数据并支持修改保存。下午开发了资料类型管理模块，实现了类型的增删改查功能。资料类型模块功能相对简单，但它是学习资料管理的基础支撑。晚上整理了代码，将重复的表格操作逻辑抽取为公共方法，提升了代码复用性。

今天的工作让我认识到代码复用和组件抽象的重要性，为后续开发提供了更好的思路。

---

## 第六天

今天开发学习资料管理模块，这是管理员端的核心功能之一。上午设计了资料列表页面，使用卡片布局展示资源信息，包含标题、封面、作者、浏览量、下载量等字段。下午实现资料分类筛选功能，对接了资料类型列表接口，支持按类型筛选学习资源。开发了新增资料弹窗，使用 el-upload 组件实现封面上传和文件上传功能。晚上对接了资料管理的后端接口，完成了资料的完整 CRUD 操作。

学习资料模块涉及文件上传功能较多，通过今天的开发我掌握了 FormData 文件上传的技巧。

---

## 第七天

今天继续完善学习资料管理模块，重点开发资料编辑和详情查看功能。上午实现了资料编辑功能，支持修改资料的基本信息和文件资源。下午开发了资料详情页面，展示了资源的完整信息和统计数据的可视化呈现。晚上添加了资料状态管理功能，管理员可以控制资料的发布状态，未发布的资料学生端不可见。

资料管理模块的开发让我理解了资源管理系统的完整业务流程，提升了复杂功能的设计能力。

---

## 第八天

今天开发试卷管理模块，这是考试系统的重要组成部分。上午设计了试卷列表页面，使用表格组件展示试卷信息，包含名称、说明、时长、总分、状态等字段。下午实现新增试卷弹窗，添加了试卷名称、考试时长、总分等必填字段，使用表单验证确保数据完整性。开发了试卷状态管理功能，支持发布和下架试卷操作。晚上对接了试卷管理的后端接口，完成了试卷管理的增删改查功能。

试卷管理模块的开发让我理解了考试系统的核心数据结构，为试题管理打下了基础。

---

## 第九天

今天是实训第九天，开发试题管理模块和考试记录查看功能。上午设计试题列表页面，支持按试卷筛选和关键词搜索，展示题目名称、题型、分值等信息。下午开发新增试题弹窗，支持单选题、多选题、判断题、填空题四种题型。实现了选项配置的动态表单，单选题和多选题可以动态添加删除选项。晚上开发了考试记录查看功能，管理员可以查看所有学生的考试记录和答题详情。

试题管理涉及多种数据结构的处理，通过今天的开发提升了我的数据处理能力。

---

## 第十天

今天是实训最后一天，完善各模块细节并优化用户体验。上午检查了留言管理、公告管理、轮播图管理三个模块的功能完整性，修复了发现的问题。下午进行了整体测试，确保各模块之间的数据交互正常。优化了页面加载速度，使用路由懒加载减少首屏加载时间。晚上整理了项目文档，编写了模块开发说明和使用指南。

实训总结会上，我汇报了负责模块的开发成果，得到了团队的认可。十天的实训让我收获颇丰，不仅掌握了 Vue 2 前端开发技术，更提升了解决实际问题的能力。感谢团队成员的帮助和支持，这次实训经历将是我职业发展的宝贵财富。
