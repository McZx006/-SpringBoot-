# 第三阶段学习资料模块审核清单

## 1. 本阶段目标

本阶段聚焦学习资料模块，把“资料列表 + 资料详情”补成更完整的学习闭环，重点覆盖预览入口、下载统计、资料评论，以及后台资源管理对下架资料的可见性。

## 2. 本阶段新增内容

### 后端新增

| 模块 | 内容 |
|---|---|
| 资料详情 | 查看详情时自动累加浏览次数 |
| 资料下载 | 新增资料下载业务接口，并累加下载次数 |
| 资料评论 | 新增评论列表接口与发表评论接口 |
| 资源分页 | 新增 `publicOnly` 参数，学员端只看已发布资料，后台可看全部资料 |

### 学员端新增

| 模块 | 内容 |
|---|---|
| 资料列表 | 增加类型、浏览量、下载量展示 |
| 资料详情 | 新增在线预览按钮 |
| 资料详情 | 新增评论列表与评论发表区域 |
| 资料下载 | 下载后前端同步更新下载数显示 |

### 数据脚本新增

| 文件 | 内容 |
|---|---|
| `database/init.sql` | 新增学习资料评论演示数据 |
| 根目录 `online_teaching_init.sql` | 同步新增学习资料评论演示数据 |

## 3. 当前已覆盖的学习资料能力

1. 资料分类筛选与关键词查询。
2. 资料详情查看。
3. 在线预览入口。
4. 下载统计。
5. 资料收藏。
6. 资料评论查看与发表。

## 4. 当前仍保留到下一轮的内容

1. 更完整的封面图片显示。
2. PDF/视频的页面内嵌预览，而不只是新窗口打开。
3. 后台资料评论管理。
4. 下载权限和文件类型限制细化。
5. 资料详情相关推荐或热门资料推荐。

## 5. 建议你本轮重点审核

1. 资料详情页结构是否接受：预览、下载、收藏、评论这几块组合是否符合预期。
2. 资料评论是否接受：当前采用简单文本评论，无楼中楼和审核流。
3. 下载统计逻辑是否接受：调用资料下载业务接口后再跳转文件地址。
4. 后台资源管理是否接受：可查看下架资料，不再只显示发布状态的数据。

## 6. 审核通过后的下一阶段建议

如果这一轮通过，建议下一轮直接进入考试模块主流程：

1. 试卷列表细化。
2. 题型渲染与答题交互细化。
3. 考试结果页与记录详情细化。
4. 错题本展示与筛选细化。
