## 3. 本阶段不展开的内容

以下内容先保留在下一阶段，不在本轮基础框架审核里展开：

1. 更细的表单校验规则。
2. 考试倒计时、自动交卷、错题统计细节。
3. 资料预览播放器细化。
4. 后台统计图表和数据看板增强。
5. 接口自动化测试集合。

## 4. 建议你本轮重点审核的内容

1. 技术版本是否接受：JDK 8、Spring Boot 2.7.18、MySQL 8 兼容 5.7、Vue3/Vue2 双前端方案。
2. 模块划分是否接受：学员端、管理端、后端、数据库四块边界是否清晰。
3. 页面与菜单是否接受：当前路由和导航是否符合你预期。
4. 接口前缀与 Token 方案是否接受：统一 `/api` 和 `Token` 请求头。
5. 第一阶段完成范围是否接受：先审骨架，再做详细功能。

## 5. 审核通过后的下一阶段

如果这一版基础框架通过，建议下一轮按下面顺序继续：

1. 资料类型与学习资料模块细化。
2. 学员个人中心和资料收藏细化。
3. 试卷、试题、在线考试主流程细化。
4. 论坛、留言、公告和轮播图细化。
5. 后台表单校验、权限边界和测试补齐。
