# 第五阶段互动与系统模块审核清单

## 1. 本阶段目标

本阶段聚焦论坛、留言、公告、轮播图和首页系统展示，把互动与系统模块从“基础可用”补到“适合验收演示”的状态。

## 2. 本阶段新增内容

### 后端新增或修正

| 模块 | 内容 |
|---|---|
| 论坛列表 | 新增 `publicOnly` 控制，学员只看开放帖子，后台可看全部帖子 |
| 论坛详情 | 查看详情自动累计浏览量 |
| 论坛权限 | 仅本人或管理员可修改、删除帖子 |
| 论坛可见性 | 关闭帖子不允许普通学员越权直接访问 |
| 留言回复 | 增加回复内容基础校验 |
| 认证边界 | 修正公告管理接口误被公开放行的问题，公开 GET 与后台写接口分离 |
| 用户归属 | 去除互动、收藏、考试提交接口中的默认测试用户兜底，统一使用 Token 中的当前用户 |
| 公告详情 | 未发布公告不允许公开直接查看 |
| 后台论坛/公告 | 后台查询支持查看全部数据，不再只看公开内容 |

### 学员端新增或优化

| 模块 | 内容 |
|---|---|
| 首页 | 接入轮播图展示 |
| 论坛列表 | 明确只展示开放帖子 |
| 论坛详情 | 新增删帖入口，本人或管理员可删 |
| 留言反馈 | 增加回复时间和“暂无回复”展示 |
| 公告列表 | 增加发布时间展示 |
| 公告详情 | 支持头图展示 |
| 后台论坛 | 增加论坛编辑入口，可维护帖子内容与开放/关闭状态 |

## 3. 当前已覆盖的互动与系统能力

1. 论坛发帖、浏览、评论、删帖。
2. 留言提交、查看回复、后台回复与删除。
3. 公告列表、公告详情、后台公告管理。
4. 轮播图列表、后台轮播图管理。
5. 首页轮播图、资料推荐、公告推荐展示。

## 4. 当前仍保留到下一轮的内容

1. 论坛编辑入口和“我的发布”独立页面。
2. 公告详情更丰富的图文布局。
3. 轮播图上传而不是只填图片地址。
4. 留言筛选、分页和更细的状态标识优化。
5. 后台论坛/公告/留言的更细表单校验和批量操作。

## 5. 建议你本轮重点审核

1. 首页轮播图是否接受：是否满足演示观感。
2. 论坛权限边界是否接受：本人或管理员删帖、关闭帖不公开展示。
3. 留言与公告展示是否接受：发布时间、回复时间、头图这些细节是否够用。
4. 后台“查看全部数据”的管理视角是否接受。
5. 公告、轮播等后台写接口是否已满足管理员 Token 校验要求。

## 6. 审核通过后的下一阶段建议

如果这一轮通过，下一轮建议直接进入联调与验收准备阶段：

1. 后台表单校验补齐。
2. 接口测试说明整理。
3. 依赖安装与真实编译运行验证。
4. 部署与验收文档收口。
