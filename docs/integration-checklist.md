### 本轮联调修复

| 问题 | 原因 | 处理结果 |
|---|---|---|
| 资料评论返回 403 | `/api/resources/comment` 被拦截器误判为后台资源管理写接口 | 已调整权限判断，资料评论允许登录学员提交 |
| 轮播图新增后列表查不到 | 轮播图列表只查询 `name LIKE 'banner%'`，后台可新增其他名称导致保存后不可维护 | 已改为轮播图管理查询 `config` 表全部配置记录 |
| IDEA 启动后前端代理 ECONNREFUSED | 前端已启动但后端 `8080` 未启动，或旧后端进程占用导致新后端未成功启动 | 当前后端 `8080` 已有 Java 进程监听且接口返回正常；若重新运行 IDEA 后报端口占用，先停止旧 Backend 运行项再启动 |
| 学员端提示 `/src/main.js` 加载失败 | 上一次并发启动过程中 Vite 服务未稳定就绪或被旧进程/缓存干扰 | 已单独启动学员端并验证 `/`、`/src/main.js` 均返回 200，源码文件存在 |
