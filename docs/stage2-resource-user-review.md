# 第二阶段资源与用户模块审核清单

## 1. 本阶段目标

本阶段围绕“资源与用户模块”推进，不展开考试、论坛、留言等复杂业务细节。重点确认管理员维护资源基础数据、查看收藏记录，以及学员维护个人资料这三条主线。

## 2. 本阶段新增内容

### 后端新增

| 模块 | 内容 |
|---|---|
| 资料类型 | 新增分页、保存、修改、删除接口 |
| 收藏管理 | 管理员访问收藏分页时可查看平台全部收藏记录 |
| 个人资料 | 新增当前登录用户资料查询与更新接口 |
| 权限边界 | 收藏删除接口纳入管理员权限控制 |

### 管理端新增

| 模块 | 内容 |
|---|---|
| 资料类型管理 | 新增后台菜单、路由、列表与表单 |
| 收藏管理 | 新增后台菜单、路由、收藏记录列表与删除 |
| 列表页结构 | `ListPage` 改为按模块输出不同表格列 |

### 学员端新增

| 模块 | 内容 |
|---|---|
| 个人中心 | 从只读展示升级为可编辑资料表单 |
| 资料维护 | 支持修改学号、姓名、性别、手机号、邮箱、头像地址 |
| 密码维护 | 个人中心支持填写新密码并一起提交 |

## 3. 当前已覆盖的第二阶段范围

1. 学员个人资料查看与修改。
2. 管理员资料类型基础维护。
3. 管理员查看和删除收藏记录。
4. 资源与用户模块所需的公共接口和菜单入口。

## 4. 当前仍保留到下一轮的内容

1. 学习资料评论细化。
2. 资料在线预览播放器细化。
3. 学员头像文件上传，而不是仅填写地址。
4. 管理端资料类型/收藏管理的更细筛选和校验。
5. 修改密码独立页面与旧密码校验。

## 5. 建议你本轮重点审核

1. 后台菜单是否接受：是否保留“资料类型管理”和“收藏管理”这两个独立入口。
2. 学员个人中心表单字段是否接受：学号、姓名、性别、手机号、邮箱、头像地址、新密码。
3. 收藏管理权限是否接受：管理员查看全站收藏，学员只看自己的收藏。
4. 资料类型维护方式是否接受：当前采用简单列表加弹窗表单。

## 6. 审核通过后的下一阶段建议

如果这一轮通过，下一轮建议直接进入：

1. 学习资料模块细化：资料评论、预览、下载统计。
2. 考试模块细化：试卷、试题、答题、记录、错题本。
3. 后台表单校验和错误提示增强。
