# 第四阶段考试模块审核清单

## 1. 本阶段目标

本阶段聚焦考试主流程，把试卷列表、进入考试、答题提交、结果查看、考试记录详情串成一条可演示闭环。

## 2. 本阶段新增内容

### 后端新增

| 模块 | 内容 |
|---|---|
| 试卷分页 | 新增 `publicOnly` 参数，学员端只看发布试卷，后台可看全部试卷 |
| 提交考试 | 提交后返回 `recordId`，用于跳转结果页和记录详情页 |
| 考试记录详情 | 返回答题明细、用户答案、正确答案、对错状态、总分 |
| 权限边界 | 考试记录详情限制为本人或管理员可查看 |

### 学员端新增

| 模块 | 内容 |
|---|---|
| 试卷列表 | 支持试卷名称搜索 |
| 答题页 | 增加剩余时间展示和自动交卷 |
| 结果页 | 根据 `recordId` 查看本次考试结果，并跳转答题详情 |
| 考试记录 | 新增“查看详情”入口 |
| 错题本 | 新增“查看错题”入口，跳转同一详情页 |
| 记录详情 | 新增独立答题详情页，展示每题对错和答案解析 |

## 3. 当前已覆盖的考试能力

1. 试卷列表查看与搜索。
2. 进入考试并按题型答题。
3. 提交试卷并自动判分。
4. 倒计时结束自动交卷。
5. 结果页查看得分、对错题数。
6. 考试记录列表与记录详情查看。
7. 错题本列表跳转到对应记录详情。

## 4. 当前仍保留到下一轮的内容

1. 离开考试页面的二次确认提示。
2. 题目标记、未答统计和进度增强。
3. 错题本独立按题目维度展示，而不是按记录维度查看。
4. 管理端考试记录详情与筛选增强。
5. 更细的题型校验和防重复提交提示。

## 5. 建议你本轮重点审核

1. 答题页结构是否接受：题号导航、倒计时、上一题/下一题、提交试卷。
2. 结果页和记录详情是否接受：是否满足课程演示需要。
3. 试卷分页边界是否接受：后台可看全部试卷，学员只看已发布试卷。
4. 记录详情权限是否接受：仅本人或管理员可查看。

## 6. 审核通过后的下一阶段建议

如果这一轮通过，建议下一轮进入互动与系统模块：

1. 论坛发布与详情细化。
2. 留言反馈和后台回复细化。
3. 公告与轮播图展示优化。
4. 后台表单校验、提示和测试补齐。
